# The Night's Watch

Security and privacy.

> The shield that guards the realms of men.

Motto: oath excerpt; see [provenance](../sources.md).

## When to use

Trust, permissions, sensitive information, identity, retention and security-sensitive changes.

## Axioms

1. **Make trust boundaries explicit.** Identify assets, threats, identities and permitted actions.
2. **Grant the minimum necessary authority.** Enforce permissions where protected actions occur.
3. **Collect and retain only what is needed.** Define purpose, access, retention and deletion for sensitive information.
4. **Prove the defenses.** Test unauthorized paths, abuse cases and privacy guarantees.

## Application and evidence

Inspect the actual affected trust boundary and data lifecycle. Prove relevant allowed and denied actions and retention/deletion behavior. Size controls to the project's real threat model. The Whisper Network's telemetry must obey these privacy rules.
